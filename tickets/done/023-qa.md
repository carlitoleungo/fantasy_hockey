### Test plan (written before reading Engineer's verification)

- **AC1** (`GET /auth/logout` + `/?logged_out=1` shows banner): hit `GET /?logged_out=1` with no session cookie; assert 200 and "You have been logged out." in body. The banner block must precede the `leagues is none` branch in the template so it fires for unauthenticated requests.
- **AC2** (`GET /` no session → 200 + login CTA): hit `GET /` with no cookie; assert 200, `href="/auth/login"`, "Log in with Yahoo" in body, no redirect.
- **AC3** (`GET /` with valid session → league list, no regression): hit `GET /` with a valid session; assert 200, league names visible, "Log in with Yahoo" absent.
- **AC4** (`POST /leagues/select` still gated): hit `POST /leagues/select` with no cookie; assert 302 to `/auth/login`.
- **optional_user failure paths**: read `web/middleware/session.py` and confirm (a) no `raise RequiresLogin()` exists inside `optional_user`, (b) all three failure paths (`no cookie`, `row not found`, `refresh failure`) `return None`, (c) the stale-session DELETE path calls `db.commit()` before `return None`.
- **Template `is none` check**: confirm template uses `{% if leagues is none %}`, not `{% if not leagues %}`, so an authenticated user with zero leagues sees the league list branch, not the login CTA.
- **Banner placement**: confirm the banner block comes before the `{% if leagues is none %}` branch in `home.html` so it fires for both auth states.
