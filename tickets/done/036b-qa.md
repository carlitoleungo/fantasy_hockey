### `/demo/overview/head-to-head` — the fourth branch was correct to migrate

The Engineer flagged this as broader than the AC's literal wording. **It was required, not
scope creep.** Three reasons:

1. The ticket's Notes say "cover **each** full-page branch that extends `base.html`", and
   `overview/head_to_head.html` extends `base.html`.
2. Both head-to-head handlers live in `web/routes/overview.py`, which is in the ticket's
   `Touches` list. No file outside `Touches` was needed.

   to `/auth/login`, which is exactly the bug in the ticket's "Why".

The Engineer also added it to `DEMO_PAGES`, so all three demo nav tests cover it.
