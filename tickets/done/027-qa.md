### AC2 fidelity assessment
The ticket text asserts the literal `table_url="/demo/overview/table"`. That literal string does **not** appear in the rendered HTML — `table_url` is a template context key, rendered at `web/templates/overview/index.html:18` as `hx-get="{{ table_url }}"`. The Engineer's adaptation (asserting `hx-get="/demo/overview/table"` present and `hx-get="/overview/table"` absent) checks the actual rendered output and is a faithful, stronger cover of AC2's intent: it proves HTMX targets the demo fragment and not the authenticated one. The `hx-get="` anchor on the negative assertion correctly prevents the demo path (`hx-get="/demo/overview/table"`) from matching the authenticated pattern as a substring. Accepted.
